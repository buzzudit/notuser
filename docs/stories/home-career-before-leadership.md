# Home career context before leadership

## Summary
Move the homepage Leadership section below Career Context so visitors first see career proof before the leadership model.

## Problem
The previous order introduced leadership behaviors before the career progression evidence. For scanning visitors, the proof should come first and the operating model should follow it.

## Desired outcome
The homepage presents Career Context before Leadership while preserving existing content, layout, and visual language.

## In scope
- Move the Leadership section below Career Context.
- Keep existing Leadership and Career Context copy unchanged.
- Preserve existing section IDs and styling.

## Out of scope
- Rewriting section content.
- Changing cards, metrics, timeline, or partner feedback.
- Redesigning the homepage.

## Acceptance criteria
1. Career Context appears before Leadership on the homepage.
2. The Leadership section remains below Career Context and above Partner Feedback.
3. Existing section IDs remain unchanged.
4. Existing responsive styling is preserved.
5. `lint` and `build` pass.

## Definition of done
- Homepage section order is updated.
- Story documentation is added.
- Local `lint` and `build` pass.
